New-OptionSet

SYNOPSIS

Creates a numbered list of options for display or selection purposes.

SYNTAX

New-OptionSet [-Options] <String[]> [-ProgressAction <ActionPreference>] [<CommonParameters>]

DESCRIPTION

The New-OptionSet function takes an array of options and formats them as a numbered list, starting from 1. This is useful for creating menus, displaying choices, or formatting options for user selection.

EXAMPLES

EXAMPLE 1

New-OptionSet -Options @('Red', 'Blue', 'Green')

Output: 1. Red 2. Blue 3. Green

EXAMPLE 2

$colors = @('Red', 'Blue', 'Green', 'Yellow')
New-OptionSet -Options $colors

Output: 1. Red 2. Blue 3. Green 4. Yellow

EXAMPLE 3

New-OptionSet -Options 'Option A', 'Option B', 'Option C'

Output: 1. Option A 2. Option B 3. Option C
